# Accuracy Report

Generated by `npm run accuracy:report --workspace server` from
`test-data/synthetic_transactions.csv` (704 transactions,
2026-03 to 2026-09).

The whole deterministic pipeline runs here — CSV parse, merchant
normalization, duplicate detection, the rule engine, anomaly detection — and is
scored against the ground truth `server/prisma/seed-data.ts` recorded when it
planted each edge case. No database and no model call, so the numbers are
reproducible from a bare checkout and any change to the rules or the normalizer
moves them immediately.

### Not crying wolf

The stronger claim, and the one §8 case 5 actually turns on: of the 82 distinct merchants in the dataset, 13 are billed on a fixed day each month by the generator. The recurring-charge classifier finds 13 of them and misreads 0 of the 69 everyday merchants — including the daily coffee, which appears in small, similar amounts across six months and is exactly what a subscription looks like from far enough away.
